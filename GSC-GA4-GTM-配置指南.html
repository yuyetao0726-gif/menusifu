② Google Search Console（核心任务）

  1. 打开 search.google.com/search-console，用 Google 账号登录。
  2. 点右上角 「添加资源」（Add property）。
  3. 左侧选 「网址前缀」，输入 https://sifumenu.huoban.men/，点继续。
  4. 在「验证所有权」里展开 HTML 标记，会看到类似：
    <meta name="google-site-verification" content="AbC123...">
    只复制 content 里的那串值（不要复制整行）。
  5. 把这串值填进 site.config.json 的 gsc.verificationCode。
  6. 运行脚本并部署（见第 ⑤ 步），然后回到 GSC 点 「验证」。
验证前务必先部署。如果还没 push，Google 抓到的页面里没有这个 meta，验证必然失败。Cloudflare 自动部署约需 1–2 分钟，失败就等两分钟再点。

验证通过后，再做完这两件事（很重要）

  • 提交站点地图：左侧「站点地图」→ 输入 sitemap.xml → 提交。状态显示「成功」即被读取。
  • 请求编入索引：顶部「网址检查」→ 粘贴首页 URL → 回车 → 「请求编入索引」，三个页面都做一遍。
可选更强方案（网域资源）：添加资源时选「网域」并填 huoban.men，需在 Cloudflare DNS 加一条 TXT 记录 google-site-verification=...。好处是一次验证覆盖所有子域名。若走这条路，把 gsc.verificationMethod 改成 dns。

③ GA4（加分项）

  1. 打开 analytics.google.com → 左下角齿轮「管理」→「创建」→「媒体资源」。
  2. 名称填 MenuSifu，国家选 United States，币种 USD，下一步后选「网站」。
  3. 数据流：网站网址填 https://sifumenu.huoban.men，名称 MenuSifu Web。
  4. 创建后会显示衡量 ID（G-XXXXXXXXXX），复制它。
  5. 填进 site.config.json 的 ga4.measurementId。

④ GTM（加分项）

  1. 打开 tagmanager.google.com →「创建账号」。
  2. 容器名 MenuSifu，目标平台选 网页（Web）。
  3. 创建后顶部会出现容器 ID GTM-XXXXXX，复制填进 gtm.containerId。
  4. 在 GTM 里挂上 GA4（这样 GA4 由 GTM 统一加载）：
    左侧「代码」→「新建」→ 代码配置选 Google Analytics：GA4 配置 → 衡量 ID 填刚才的 G-XXXX → 触发条件选 All Pages → 保存 → 右上角「提交/发布」。
为什么不在页面里直接写 gtag？配置里 ga4.viaGtm = true 时，脚本不会往页面插独立的 GA4 代码，GA4 完全由 GTM 容器加载 —— 这是业界标准做法，避免 page_view 被重复统计。若你想直连，把 viaGtm 改成 false 重新运行脚本即可。

⑤ 应用配置并部署

三个 ID 都填好后，在项目目录执行：

python apply-analytics.py

git add .
git commit -m "feat: add GSC verification, GA4 and GTM"
git push

Cloudflare 会自动部署。部署完成后校验线上是否生效：

python apply-analytics.py --check

全部显示 PASS 就说明代码已正确上线。

⑥ 最后确认三处都亮绿灯

  • GSC：显示「已验证所有权」；站点地图状态「成功」。
  • GA4：左侧「报告 → 实时」，用自己的手机/浏览器打开网站，实时用户数应变为 1。
  • GTM：右上角「预览」→ 输入 https://sifumenu.huoban.men → 显示「已连接」即容器生效。
若 GA4 实时无数据：确认 GTM 容器已「提交/发布」（不只是保存），且 GA4 配置代码的衡量 ID 没填错。
